# Greenwich Little Learners — Daycare Website

## Run Locally

**Option 1 — No install required (recommended):**

Download or clone the repo, then double-click `index.html` — it opens directly in your browser.

Or from the terminal:

```bash
# Windows
start index.html

# Mac
open index.html

# Linux
xdg-open index.html
```

**Option 2 — Local server:**

```bash
npx serve . -p 3000
```

Then open **http://localhost:3000** in your browser (Node.js required).

## About

A modern, mobile-responsive website for **Greenwich Little Learners**, a daycare and early education center based in Greenwich, CT.

### Sections

- **Home** — Hero, trust bar, stats
- **About Us** — History, values, team bios
- **Programs** — Infant Care, Toddler Program, Pre-K Academy + daily schedule
- **Admissions** — Enrollment steps, tuition rates, FAQ
- **Gallery** — Filterable photo grid with lightbox
- **Testimonials** — Parent reviews
- **Contact** — Map, hours, inquiry form

### Tech

- Pure HTML/CSS/JS — single file, no build step
- Google Fonts (Nunito, Quicksand)
- Font Awesome icons
- Images via Unsplash
- Mobile responsive (breakpoints at 1024px, 768px, 480px)
- SEO meta tags targeting Greenwich CT daycare keywords
